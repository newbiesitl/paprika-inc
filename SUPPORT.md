# Support

Start with the [README](README.md), [company definition](company/README.md), and [development plan](docs/DEVELOPMENT.md). Inc is at the repository foundation stage; automatic company creation, transfer, and installation are not available yet.

Use [issues](https://github.com/newbiesitl/paprika-inc/issues) for reproducible bugs, design questions, features, and improvements. Include the Inc commit, Messenger pin when relevant, expected behavior, and redacted evidence. Do not include private conversation data or credentials. Suspected vulnerabilities use [private reporting](SECURITY.md).

Messenger-only problems belong in [Paprika Messenger](https://github.com/newbiesitl/paprika-messenger/issues); integration and adoption problems belong here. Support is best effort, without a guaranteed response time.
