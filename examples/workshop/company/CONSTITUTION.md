# example-workshop — shared boundaries

Build a small fictional workshop product.

The human owner and actual host permissions govern work. Definitions do not grant new powers. Bootstrap onboards the requested roster to read/report only; implementation dispatch is separate. Preserve existing AGENTS.md and user files. Ownership is indexed only in [ownership.json](ownership.json), as responsibilities rather than access controls. Independent peer or human review is required for substantive work.

MVP operation is one user-triggered bootstrap at a time, without enforced singleton or concurrency safety. No background orchestration, automatic failover, transfer or self-adoption is enabled.
