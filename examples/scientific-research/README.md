# Fictional research studio and public pilot

The [blueprint](blueprint.json) renders the adjacent [company manifest](company/company.json),
[researcher contract](company/roles/scientific-researcher/agent.md) and canonical
[ownership map](company/ownership.json). It is a portable example, not a change
to Paprika Inc's development roster. Human review is configured without creating
a reviewer chat. No live company or skills have been installed by these files.

The [brief](pilot/brief.md), [claim/evidence table](pilot/evidence.csv),
[bibliography](pilot/sources.bib) and [provenance](pilot/provenance.json) form a
small public pilot input/output example for eventual live acceptance. This is
an abstract-level illustration, not a systematic review or a certification of
the upstream tools. It requires no paid services or confidential input.
