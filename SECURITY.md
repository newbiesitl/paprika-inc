# Security policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/newbiesitl/paprika-inc/security/advisories/new). Do not publish credentials, private messages, machine bindings, checkpoints, or exploit details in issues and PRs.

Include the affected Inc commit and pinned Messenger version, the expected boundary, impact, and a minimal reproduction with invented data on a system you control. Ordinary non-security problems belong in [Support](SUPPORT.md).

Security fixes target current `main`; there are no released Inc versions or independent backport commitments yet. Messenger vulnerabilities can also be reported through [its security policy](https://github.com/newbiesitl/paprika-messenger/blob/main/SECURITY.md). Inc must separately assess and adopt any upstream fix.

[@newbiesitl](https://github.com/newbiesitl) handles reports on a best-effort basis without a promised response time or bounty. Coordinate disclosure in the private advisory. Report hosting or platform vulnerabilities to the relevant provider.
